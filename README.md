# Descripcion 
- El sitio cuenta con múltiples páginas interconectadas mediante enlaces de navegación, entre las que se incluyen la página principal, catálogo de productos, detalles de productos, registro de usuarios, inicio de sesión y carrito de compras. Los productos están organizados por categorías como laptops, accesorios, monitores, teclados y audífonos, mostrando información detallada de cada uno mediante tablas que contienen su descripción, características, precio, disponibilidad e interfaz de compra.
