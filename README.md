# Descripcion
### Funcionalidades interactivas con JavaScript
se incorporo mediante un archivo externo `script,js` para agregar interactividad y mejorar la experiencia del usuario en la pagina

### Principales Funcionalidades Implementadas:
- Galeria de imagenes interactiva
  - al hacer clic sobre una imagen, se abre un modal que muestra la fotografia en un tamaño mayor junto con una descripcion. El modal puede cerrarse mediante el boton correspondiente o haciendo clic fuera de la imagen
- Calculadora de Cotizacion:
  - permite ingresar el numero de asistentes, seleccionar un paquete turistico y agregar servicios adicionales como transporte, alimentacion y equipo. `JavaScript` calcula automaticamente el costo toal sin necesidad de recargar la pagina
- Buscador de actividades:
  - permite buscar actividades de la excursion en tiempo real. Los elementos de la lista se filtran automaticamente conforme el usuario escribe
- Formulario de reservacion:
  - se implemento validacion mediante `JavaScript` para comprobar que los campos requeridos esten completos y mostrar un mensaje dinamico de confirmacion al registrar una solicitud
- Testimonio aleatorios:
  - se agregaron arreglos de nombres y comentarios de visitantes. `JavaScript` selecciona aleatoriamente un testimonio y permite mostrar una nueva opinion mediante un boton

---

Para implementar estas funcionalidades se utilizaron elementos de manipulacion del DOM como `querySelector`, `getElementById`, `addEventListener` y `classList`, permitiendo responder a las acciones realizadas por el usuario sin nececesidad de recargar la pagina
