# Descripcion
### Mejoras en HTML
- se optimizo la estrucutra del documento utilizando elementos semanticos como `<header>` y `<footer>`
- se incoporo el atributo `alt` en todas la imagenes para mejorar la accesibilidad
- se organizaron las tablas mediante clases CSS para facilitar el mantenimiento del codigo
- se corrigio la estructura general del documento, mejoranto la legibilidad y el orden del codigo

### Estilos aplicados con CSS
- se creo un archivo externo `style.css` para separar el diseño del contenido
- se aplico una paleta de colores inspidad en tonos azules para representar el Lago de Atitlan
- se diseño un encabezado con degradado y sombra para mejorar la presentacion
- se presonalizo el menu de navegacion con efectos visualies al pasar el cursor sobre los enlaces
- se mejoro la apariencia de las tablas mediante bordes, colores, sombras y espaciado
- se agregaron esquinas redondeadas y sombras a las imagenes para lograr una apariencia mas moderna
- se implementaron efectos de transicion y aumento de tamaño en las imagenes al pasar el cursos
- se diseño un pie de pagina con un estilo uniforme respecto al resto del sitio

### Diseño responsivo
- se utilizaron Media Queries para adaptar la pagina a diferentes tamaños de pantalla
- se ajusto el tamaño de los textos, tablas e imagenes para mejorar la visualizacion en tabletas y telefonos moviles
- se permitio el desplazamiento horizontal de las tablas cuando el ancho de la pantalla es reducido, evitando que el contenido se desborde
