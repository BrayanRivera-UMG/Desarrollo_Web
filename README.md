# Tienda Tecnológica - Proyecto Web

## Descripción

Este proyecto es una tienda en línea de productos tecnológicos desarrollada como parte del curso de Desarrollo Web. La página web permite a los usuarios explorar un catálogo de productos, ver detalles de cada artículo y simular un proceso de compra.

El sitio está diseñado con un enfoque en la experiencia de usuario, ofreciendo una navegación intuitiva y una interfaz atractiva para mostrar diferentes categorías de productos tecnológicos como:

- **Laptops**: De marcas como Apple, Dell, HP, Lenovo y ASUS
- **Audífonos**: De Sony, Bose, JBL, Sennheiser y más
- **Periféricos**: Teclados, mouse, monitores y accesorios
- **Accesorios**: Cámaras web, micrófonos, reguladores de voltaje y memorias USB

## Funcionalidades Principales

- **Catálogo de productos**: Visualización organizada de todos los productos disponibles
- **Detalle de producto**: Información completa de cada artículo al seleccionarlo
- **Carrito de compras**: Sistema para agregar productos y simular una compra
- **Autenticación de usuarios**: Pantallas de inicio de sesión y registro
- **Diseño responsivo**: Adaptable a diferentes dispositivos y tamaños de pantalla

## Tecnologías Utilizadas

- **React**: Framework para construir la interfaz de usuario
- **CSS**: Estilizado y diseño visual de la página
- **JavaScript**: Lógica y funcionalidades interactivas
- **Git**: Control de versiones del proyecto

## Estructura del Proyecto

El proyecto está organizado en componentes reutilizables que facilitan el mantenimiento y la escalabilidad:

- **Componentes de layout**: Barra de navegación y pie de página
- **Páginas**: Inicio, productos, carrito, detalle, inicio de sesión y registro
- **Datos**: Archivo centralizado con la información de todos los productos
- **Recursos**: Imágenes y archivos estáticos necesarios para el funcionamiento
