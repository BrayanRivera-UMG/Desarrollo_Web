# Descripcion
- Este proyecto consiste en el desarrollo de una página web informativa en HTML puro, creada para promocionar una excursión turística al Lago de Atitlán, Guatemala. El sitio está estructurado en secciones clave que incluyen un encabezado con título y mensaje de bienvenida, un índice de navegación con enlaces internos, una descripción detallada del lugar con su ubicación y características principales, una galería con cuatro imágenes representativas del paisaje, una tabla de itinerario que detalla horarios y actividades durante la excursión, y una lista con diez actividades turísticas disponibles
